# YHMS Cleaned Frontend

نسخه بازسازی‌شده رابط کاربری پروژه مدیریت شفاخانه.

## تغییرات
- تبدیل `index.html` به صفحه عمومی معرفی شفاخانه.
- اضافه شدن `login.html`.
- انتقال CSS تکراری صفحات به یک `style.css` مشترک.
- اضافه شدن `script.js` مشترک برای منوی موبایل، جستجو، فیلتر و رفتارهای ساده.
- اصلاح لینک‌های داخلی و حذف لینک‌های بی‌هدف `#`.
- یکسان‌سازی RTL، فونت فارسی و طراحی.
- طراحی Responsive برای موبایل، تبلت و دسکتاپ.
- اصلاح متن‌های ناهماهنگ مانند «مشاهده پروژه» به «مشاهده پرونده».
- ایجاد `dashboard.html` جداگانه برای داشبورد.

## مهم
این نسخه بر اساس فایل‌های HTML/CSS ارائه‌شده ساخته شده است. در فایل ارائه‌شده کد PHP، اتصال MySQL یا ساختار دیتابیس وجود نداشت؛ بنابراین ورود و عملیات CRUD فعلاً نمایشی هستند و برای اتصال واقعی باید با PHP/MySQL پروژه اصلی یکپارچه شوند.

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید.
برای نسخه واقعی PHP، فایل‌ها را داخل پروژه PHP خود قرار دهید و لینک‌های backend را به مسیرهای واقعی تغییر دهید.
