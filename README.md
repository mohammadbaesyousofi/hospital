سیستم مدیریت شفاخانه یوسفی (YHMS) یک رابط وب برای مدیریت فعالیت‌های شفاخانه ی مانند پزشکان، پرستاران، بیماران، نوبت‌دهی و پرونده‌های پزشکی است. این پروژه با رابط فارسی و راست‌چین طراحی شده و به عنوان یک پروژه عملی مدیریت شفاخانه ساخته شده است.

این سیستم شامل امکاناتی مانند صفحه اصلی شفاخانه، صفحه ورود، داشبورد مدیریت، مدیریت پزشکان، مدیریت پرستاران، مدیریت بیماران، مدیریت نوبت‌ها، پرونده‌های پزشکی، تنظیمات سیستم، فرم‌های ثبت‌نام برای پزشک، پرستار و بیمار، جستجو و عملیات مدیریتی، طراحی واکنش‌گرا برای دسکتاپ، تبلت و موبایل، رابط فارسی RTL و ذخیره‌سازی داده‌ها در مرورگر با localStorage است.

صفحات پروژه عبارتند از index.html برای صفحه اصلی، login.html برای ورود، dashboard.html برای داشبورد، doctors.html برای مدیریت پزشکان، nurses.html برای مدیریت پرستاران، patients.html برای مدیریت بیماران، appointments.html برای مدیریت نوبت‌ها، medical_records.html برای پرونده‌های پزشکی، setting.html برای تنظیمات سیستم، register_doctor.html برای ثبت‌نام پزشک، register_nurse.html برای ثبت‌ نام پرستار و register_patient.html برای ثبت‌ نام بیمار.

تکنولوژی‌های استفاده شده در این پروژه شامل HTML5، CSS3، JavaScript، طراحی واکنش‌گرا، LocalStorage و فونت Vazirmatn از Google Fonts است.

ساختار پروژه به این صورت است که همه فایل‌های HTML در کنار فایل style.css و script.js و README.md قرار دارند.

برای اجرای پروژه نیازی به نصب خاصی نیست. کافی است پروژه را دانلود یا Clone کنید، پوشه را در VS Code باز کنید و فایل index.html را در مرورگر باز کنید. برای توسعه می‌توانید از افزونه Live Server در VS Code استفاده کنید.

فرم‌های ثبت‌نام به صفحات مدیریتی مربوطه متصل هستند. register_doctor.html به doctors.html، register_nurse.html به nurses.html و register_patient.html به patients.html متصل است. در نسخه فعلی، داده‌های ثبت‌نام در localStorage مرورگر ذخیره می‌شوند و در سرور ذخیره نمی‌شوند.

این مخزن شامل نسخه فرانت‌اند سیستم مدیریت شفاخانه است. در آینده می‌توان آن را به بک‌اند و دیتابیس متصل کرد تا از احراز هویت واقعی کاربران، نشست‌های PHP، دیتابیس MySQL، ذخیره‌سازی دائمی اطلاعات پزشکان، پرستاران و بیماران، ذخیره‌سازی نوبت‌ها، مدیریت پرونده‌های پزشکی، نقش‌ها و سطوح دسترسی و اعتبارسنجی سمت سرور پشتیبانی کند.

هدف اصلی این پروژه، ساخت یک رابط کاربردی برای مدیریت شفاخانه و تمرین کار با چند صفحه وب متصل، فرم‌ها، قابلیت‌های JavaScript و طراحی واکنش‌گرا است.
